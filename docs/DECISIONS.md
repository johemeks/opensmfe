# Decisions behind OpenSmFe v0.1

*Plain-language note: every judgment call in this release, what was chosen, and who chose it. If you change one in a later version, record it here.*

| Decision | Choice for v0.1 | Who and when |
|---|---|---|
| Text-mined cross-check database | None in v0.1. The cross-check is deferred to a later version. | J. C. Ejeka, 2026-10-08 |
| Compound scope | Sm2Fe17-based (2:17) and TbCu7-type (1:7) families, nitrided or not. SmFe12 (ThMn12-type) is deferred to v1.1. | Proposed default, approved by J. C. Ejeka, 2026-10-08 |
| Headline coercivity | Intrinsic coercivity (Hcj) where the paper says so; otherwise recorded as `Hc_unspecified` | Proposed default, approved 2026-10-08 |
| Room-temperature window for grade A | 290 to 305 K | Proposed default, approved 2026-10-08 |
| Unstated measurement temperature | Not assumed to be room temperature; the row stays at grade B | Proposed default, approved 2026-10-08 |
| Values read from figures | Not included; text and tables only | Proposed default, approved 2026-10-08 |
| Primary values only | Values quoted from earlier work, including all values in reviews, are not entered | Build rule, approved 2026-10-08 |
| Zheng et al. 2022 remanence (abstract 10.19 kG; results and conclusions 10.12 kG) | 10.12 kG entered, with the inconsistency flagged on the row | Proposed default, approved 2026-10-08 |
| Licenses | Data CC BY 4.0; code MIT | Proposed default, approved 2026-10-08 |
| Affiliation | Independent Researcher | J. C. Ejeka, 2026-10-08 |
| Release version | v0.1.0 (seed release). v1.0 remains the April 2027 target. | Proposed by Claude, at the author's request to publish now |
